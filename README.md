# Reach Together 🚆🤝  
**Never Travel Alone — Connect with colleagues on the same journey**

Reach Together is a web-based platform designed to help people from the **same organization** find trusted travel companions who are traveling on the **same route, date, and time**.  
The idea focuses on **safety, cost-sharing, and community**, especially for **solo and female travelers**.

---

## 🌟 Problem Statement
Many students and working professionals travel alone—often late at night or on unfamiliar routes.  
Despite multiple people from the same organization traveling on similar routes, there is **no easy way to discover and connect safely**.

**Reach Together solves this problem by enabling verified, organization-only travel matching.**

---

## 🚀 Features

### 🔐 Secure & Verified Access
- Sign up/login using **organization email only** (example: `@nitj.ac.in`)
- Prevents unknown or unverified users

### 🧳 Journey Management
- Add journeys (Train / Bus / Flight)
- Optional **PNR-based matching** for accurate train matches
- Edit or delete journeys anytime

### 🤝 Smart Matching System
- Matches based on:
  - Same route & date
  - Journey type
  - PNR (if available)
  - Departure time (±1 hour)
  - Travel preferences
- Displays **match percentage**

### 💬 Built-in Messaging
- Chat with matched travelers
- Simple, clean UI for communication

### 🌗 Dark / Light Mode
- Theme toggle with preference saved in `localStorage`

### 📱 Fully Responsive
- Works seamlessly on desktop, tablet, and mobile

---

## 🛠️ Tech Stack

**Frontend**

**Storage**
- Browser `localStorage` (for demo & prototyping)
